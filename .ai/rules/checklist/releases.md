### Before Release

- [ ] All tests pass
- [ ] No open blockers in issue tracker
- [ ] CHANGELOG.md updated
- [ ] Version bumped correctly
- [ ] Breaking changes documented
- [ ] Migration guide written (if needed)
- [ ] Deprecation warnings added (not removed without cycle)
- [ ] Documentation updated

### Release

- [ ] Create git tag with `v` prefix
- [ ] Push tag to remote
- [ ] Publish artifacts
- [ ] Create GitHub release

### After Release

- [ ] Verify artifacts in Maven Central
- [ ] Update development version to next SNAPSHOT
- [ ] Announce release
- [ ] Close milestone
- [ ] Start "Unreleased" section in CHANGELOG
